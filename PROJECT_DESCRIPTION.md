# Project Description
## Title
Digital Time Display Device with Multi-Format Visual Interface Configuration

## Abstract
A configurable digital clock implemented on a Xilinx Spartan-6 FPGA using Verilog HDL.
A clock divider creates timing pulses, synchronous counters maintain HH:MM:SS, and a
multiplexed display driver drives six 7-segment digits. Users can switch between 12-hour
and 24-hour formats and adjust hours/minutes.

## Objectives
- Implement clock division and synchronous time counters.
- Implement 12/24-hour display selection.
- Interface a multiplexed 7-segment display.
- Verify using simulation.
- Deploy to Spartan-6 FPGA.

## Note on novelty
The basic digital clock is conventional. Treat the configurable multi-format interface as
a project feature, not a patent claim, unless a proper prior-art search supports a claim.
